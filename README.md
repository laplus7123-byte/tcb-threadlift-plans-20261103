2026年11月3日時点の案1・案2・案4・案5を収録しています。

- [比較ページ](index.html)
- [案1：価格訴求](plan1.html)

- [案5：なぞる・タップするクーポン体験](plan5.html)

案2の症例比較はスクロール連動が初期状態です。下へスクロールするとアフターの割合が増え、上へ戻すと割合も戻ります。中央のつまみの上下ドラッグ、またはキーボードの矢印キーでも比較できます。手動操作後は位置を保持し、「スクロール連動に戻す」で自動表示に戻せます。症例写真にはTCB公式素材を使用しています。

各案に4問のアンケートと回答後のLP、予約CTA、症例・料金・リスクの注釈を含みます。

## プレビュー

公開サイト：https://laplus7123-byte.github.io/tcb-threadlift-plans-20261103/

ローカルでは、このフォルダで以下を実行してください。

```sh
python3 -m http.server 8000
```

`http://localhost:8000/` を開きます。ビルドや依存パッケージのインストールは不要です。
