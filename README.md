# TCB小顔リフトLP — 案1・案2

2026年11月3日時点の2案を収録しています。

- [比較ページ](index.html)
- [案1：価格訴求](plan1.html)
- [案2：FV内の症例比較](plan2.html)

案2の症例比較は手動が初期状態です。中央のつまみの上下ドラッグ、またはキーボードの矢印キーで比較できます。「スクロールでも比較する」でスクロール連動に切り替えられます。症例写真にはTCB公式素材を使用しています。

各案に4問のアンケートと回答後のLP、予約CTA、症例・料金・リスクの注釈を含みます。

## プレビュー

GitHub Pagesでルートを公開できます。ローカルでは、このフォルダで以下を実行してください。

```sh
python3 -m http.server 8000
```

`http://localhost:8000/` を開きます。ビルドや依存パッケージのインストールは不要です。

## ファイル

- `index.html`：2案の選択ページ
- `plan1.html` / `plan2.html`：各LP
- `assets/`：使用画像・共通CSS/JS
- ルートのCSS/JS：FV、アンケート、症例比較の表示と動作

公開対象に旧案・制作途中の画像・作業履歴は含めていません。
